# Free Citation Generator

Browser-based APA 7, MLA 9, Chicago, IEEE, Vancouver and ABNT citations with DOI/ISBN lookup and BibTeX export.

Powered by [CiteFast](https://github.com/gabotonatiu/citefast) (MIT) by Gabriel Tonatiu Andrade.

## Develop

```bash
npm install
npm run build
npm run preview
npm test
```

Static output is written to `dist/`. Deploy is handled separately (see `wrangler.toml`); do not deploy from agent runs unless instructed.
